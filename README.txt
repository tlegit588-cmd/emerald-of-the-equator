EMERALD OF THE EQUATOR — SPRINT 1
==================================

WHAT'S INCLUDED
- Responsive tourism homepage
- São Tomé and Príncipe island introduction sections
- Destination directory with island filters
- Interactive MapLibre map with destination pins
- Destination detail panel
- Browser text-to-speech overview
- Copy-coordinates action
- Mobile navigation
- SEO description and responsive metadata

PROJECT FILES
- index.html   Main website page
- styles.css   Layout, visual design and responsive styling
- app.js       Destination data and interactive features

HOW TO TEST
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open index.html in a modern browser while connected to the internet.
4. Test the island filters, destination list, map pins, audio button and coordinate-copy button.

IMPORTANT
- This is Sprint 1: a front-end prototype, not a complete booking platform.
- Internet is required for Google Fonts, MapLibre and map tiles, and remote photos.
- Some remote image URLs are editorial placeholders and must be replaced with verified, licensed destination photography before public launch.
- Verify all location coordinates, destination descriptions, travel access, safety details and current opening arrangements before publishing.
- The WhatsApp link is a generic placeholder. Replace it with the official contact number in international format.
- The map uses CARTO basemaps with OpenStreetMap attribution. Review provider terms and usage limits before production traffic.
- No live hotel inventory, reservations, payments or user accounts are included yet.
